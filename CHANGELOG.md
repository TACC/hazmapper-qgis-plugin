## [0.2.1] - 2026-10-30
- Mark the plugin as stable (no longer experimental)

## [0.2.0] - 2026-10-29
- Show internal COGs (as tile layers), WMS layers, and features without assets
- Keep streetview lines and photos attached to lines or polygons
- New "Pick on map" panel: feature data, photo preview and "View in Hazmapper" link
- Add attribution and Hazmapper/DesignSafe links to each layer
- Load staging and dev maps from their own GeoAPI
- Respect layer visibility and max zoom from Hazmapper; load maps with no tile layers
- Support QGIS 4; minimum QGIS version is now 3.34

## [0.1.0] - 2025-09-19
- First public release of the plugin
